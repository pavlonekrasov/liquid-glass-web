# liquid-glass-web

Physically grounded **Apple iOS 26/27 Liquid Glass** material and interactive component system for the web.

## Install

```bash
npm install liquid-glass-web motion
```

## Usage

```tsx
import {
  GlassStage,
  GlassContainer,
  GlassTabBar,
  GlassOrb,
  GlassSwitch,
  GlassSlider,
} from "liquid-glass-web";
import "liquid-glass-web/styles.css";
```

Pure zero-DOM physics utilities are available at `liquid-glass-web/core`.

See the [repository README](https://github.com/pavlonekrasov/liquid-glass-web) for full documentation, Material Lab, and Agent Skill.
